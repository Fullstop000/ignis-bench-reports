ignis · model provider pricing

The price table underlying the Est. cost and Cost / passed task columns in the benchmark reports. Sourced from each provider's public pricing page; pinned to a specific snapshot so the cost math is reproducible.

Per 1M tokens

Prices are denominated in CNY (the canonical currency on each provider's API pricing page). The USD column applies a fixed ≈1 USD = 7.10 CNY rate — the same conversion the compare reports use. Input miss is uncached input, cache hit is input matched by the provider's prompt cache, output is generated tokens.

Notes

  • kimi-2.6 / Coding Plan. In practice the run uses a flat-fee Coding Plan subscription, not pay-per-token. The cost figure shown in compare reports is the per-token equivalent at the published k2.6 API rate — useful for cross-provider comparison, not out-of-pocket for the subscriber.
  • MiniMax-M3 promo tier. The ≤512k-context standard rate is a promotional price; the enterprise tier and the larger ≤1M-context tier are higher. We pin to the rate that applied during the run; later runs will be re-pinned if MiniMax bumps the price.
  • USD conversion. Fixed at 1 USD = 7.10 CNY (mid-2026 reference rate). The conversion is applied at total-cost time, not per-token, so rounding accumulates at most once per run.
  • Formula. cost = (input − cache) × miss-price + cache × hit-price + output × out-price — same formula the compare_runs.py headline uses when --price-cny is passed for a run.
